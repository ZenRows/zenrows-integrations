# Zenrows

The `@mastra/zenrows` package exposes the [Zenrows](https://www.zenrows.com) API as Mastra-compatible tools: a scrape tool and an extract tool, and a tool for every other endpoint Zenrows offers. Zenrows handles proxies, JavaScript rendering and anti-bot protection. The tools can read pages that block typical scrapers. Each factory returns a tool created with [`createTool()`](/reference/tools/create-tool) and a typed Zod input schema.

The scrape tool returns a page's content. The extract tool returns the structured fields Zenrows parsed out of a page, such as a product's name and price, with no selectors to write. The [other tools](#more-tools) cover the rest of the API, one tool per endpoint.

## Installation

```bash npm2yarn
npm install @mastra/zenrows zod
```

Set `ZENROWS_API_KEY` in your environment. You can also pass an API key directly to any factory.

## Quick start

Use `createZenrowsTools()` to create the scrape and extract tools with shared configuration:

```typescript title="src/mastra/tools/index.ts"
import { createZenrowsTools } from '@mastra/zenrows'

export const zenrowsTools = createZenrowsTools()
// Or pass an explicit API key:
// export const zenrowsTools = createZenrowsTools({ apiKey: 'your-zenrows-api-key' })
```

The returned object contains `zenrowsScrape` and `zenrowsExtract`. `createZenrowsAllTools()` returns those and the [other tools](#more-tools).

Create a tool on its own when an agent doesn't need them all:

```typescript title="src/mastra/tools/index.ts"
import { createZenrowsExtractTool, createZenrowsScrapeTool } from '@mastra/zenrows'

export const scrapeTool = createZenrowsScrapeTool()
export const extractTool = createZenrowsExtractTool({ apiKey: 'your-zenrows-api-key' })
```

A tool reads the API key when it executes, not when you create it. A missing key fails at execution time with a configuration error.

## `createZenrowsScrapeTool()`

Creates the `zenrows-scrape` tool. Scrape fetches one URL and returns its content as Markdown by default, as plaintext, or as the page's HTML. With `css_extractor`, it returns only the fields the selectors name, as JSON text.

import { createZenrowsScrapeTool } from '@mastra/zenrows'

const scrapeTool = createZenrowsScrapeTool()

## `createZenrowsExtractTool()`

Creates the `zenrows-extract` tool. Extract returns the fields of a page as JSON, named the way the site names them. It works on any domain Zenrows has prepared. A domain that isn't prepared yet, or a page Extract doesn't recognise, throws a `ZenrowsError` with code `REQS007` and isn't charged.

```typescript
import { createZenrowsExtractTool } from '@mastra/zenrows'

const extractTool = createZenrowsExtractTool()
```

## More tools

`createZenrowsAllTools()` returns the scrape and extract tools and a tool for every other endpoint Zenrows offers:

```typescript title="src/mastra/tools/index.ts"
import { createZenrowsAllTools } from '@mastra/zenrows'

export const zenrowsTools = createZenrowsAllTools()
```

Each factory is also exported on its own, such as `createZenrowsStartCrawlTool()`. Each of these tools takes the endpoint's path, query and body fields as its input, and returns the API's answer: JSON parsed, text as a string, and a file such as a PDF as `{ contentType, base64 }`. Batch jobs and crawls run in the background: start one, then read it with the matching tools until it ends.

## Use the tools with an agent

```typescript title="src/mastra/agents/research-agent.ts"
import { Agent } from '@mastra/core/agent'
import { createZenrowsTools } from '@mastra/zenrows'

export const researchAgent = new Agent({
  id: 'research-agent',
  name: 'Research Agent',
  model: '__GATEWAY_ANTHROPIC_MODEL_SONNET__',
  instructions:
    'Read pages with the scrape tool. When you need the fields of a product, article or listing page, use the extract tool.',
  tools: createZenrowsTools(),
})
```

## Environment variables

| Variable | Description |
| - | - |
| `ZENROWS_API_KEY` | Your Zenrows API key. Used when `apiKey` isn't passed to a factory function. |
| `ZENROWS_API_URL` | Optional. Overrides the API base URL when `baseUrl` isn't passed. |
